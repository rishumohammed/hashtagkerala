# Ashtag Kerala Frontend

Vue 3 starter built with Vite, Vue Router, Pinia, Tailwind CSS, and a scalable folder structure.

## Project Structure

```text
src/
  assets/
    styles/
  components/
  composables/
  layouts/
  pages/
  router/
  services/
  stores/
```

## Environment

Create a `.env` file from `.env.example` and set:

```bash
VITE_API_BASE_URL=http://localhost:8000/api
```

## Scripts

```bash
npm run dev
npm run build
npm run preview
```
